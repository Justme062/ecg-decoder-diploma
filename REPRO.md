# Воспроизводимость чисел (repro-патч)

Проблема: метрики, зависящие от обучения нейросети, меняются от запуска к
запуску (инициализация весов, перемешивание, dropout, недетерминизм GPU).
Одно число в тексте — это один случайный прогон. Решение из двух шагов:

1. **Фиксация seed** — один и тот же прогон на той же машине повторяется.
2. **Среднее ± СКО по нескольким сидам** — число становится устойчивым к
   смене сида/машины; любой перезапуск попадает внутрь интервала, и
   переписывать текст больше не нужно. Это главное.

## Что заменить / добавить

Скопируйте файлы из этой папки в папку проекта (рядом с `train.py`), заменив
одноимённые:

- `repro.py` — **новый** файл (утилита фиксации seed);
- `run_multiseed.py` — **новый** файл (обёртка для прогона по сидам);
- `train.py`, `early_warning.py`, `augmented_training.py`,
  `latent_interpolation.py` — **заменить** (в них seed теперь читается из
  окружения, и в конце печатается служебная строка `MULTISEED ...`).

Логика и человекочитаемый вывод скриптов не изменены — добавлены только
управление сидом и одна служебная строка в конце. Обычный запуск
(`python train.py`) работает как раньше и по умолчанию использует seed = 42.

Стабильные метрики трогать не нужно — они и так воспроизводятся точно:
детекция R-пиков (92,75 / 98,9 %), baseline-AUC логрегрессий
(0,685 / 0,739 / 0,746), механистика полюсов (1,0038 против 1,0018).

## Как получить «среднее ± СКО»

Из папки с данными (`X.npy`, `F.npy`, `y.npy`, `sequences.npz`):

    python run_multiseed.py class    -k 5     # прирост классификации (гл. 2)
    python run_multiseed.py predict  -k 5     # AUC прогноза (гл. 3)
    python run_multiseed.py augment  -k 5     # эффект аугментации (гл. 4)
    python run_multiseed.py interp   -k 5     # монотонность латента (гл. 4)
    python run_multiseed.py all      -k 5     # всё сразу

`-k` — число сидов (5 достаточно, 10 надёжнее). Обёртка сама прогоняет
скрипты на сидах 0..k-1 и печатает блок **«ГОТОВО ДЛЯ ВСТАВКИ В ТЕКСТ»** —
строки вида `... : +0,8 ± 1,4 п.п. (по 5 сидам)`. Их и вставляйте.

## Как формулировать в тексте

Вместо «прирост составил +0,87 п.п.» → «прирост составил +0,8 ± 1,4 п.п.
(среднее ± СКО по 5 сидам)». Если интервал перекрывает ноль — это честно
показывает, что эффект в пределах шума (что и подтверждает межпациентный
результат). Такой формат к перезапускам иммунен.

## Разовый «канонический» прогон

Если для сохранения моделей (`base_cnn.pth`, `hybrid_cnn.pth`, предсказаний
для `statistical_significance.py`) нужен один фиксированный прогон — просто
запускайте скрипты как обычно, seed = 42 зашит по умолчанию.

> Замечание про полную битовую воспроизводимость: даже с фиксированным seed
> смена версии PyTorch/CUDA или другого GPU может сдвинуть 3–4-й знак. Именно
> поэтому итоговые числа в тексте лучше держать в форме интервала, а не одной
> цифры.
